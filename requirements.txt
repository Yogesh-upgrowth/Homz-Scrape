# wheels in recent releases. Pinning to older versions makes pip fall back to
# compiling from source, and the Rust extensions (pydantic-core, orjson) fail
# to build because their bundled PyO3 predates 3.14 support:
#
#   error: the configured Python interpreter version (3.14) is newer than
#          PyO3's maximum supported version (3.13)
#
# `requirements.lock.txt` holds the exact resolved set for reproducible
# deploys — regenerate it with `make lock`.
